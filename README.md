# 💆‍♂️ AJ Massoterapia - Página de Agendamento

Este é um produto real, funcional e responsivo, desenvolvido para otimizar o agendamento de serviços de massoterapia e apresentar informações profissionais de forma clara.

🔗 **[Acesse a aplicação em produção aqui](https://gabsqi.github.io/ajmassoterapia/)**

---

## 📝 Sobre o Projeto

O **AJ Massoterapia** foca na experiência do usuário (UX), trazendo um layout clean, organizado e intuitivo. O objetivo principal é facilitar a navegação do cliente entre a descoberta dos serviços, informações sobre a profissional e a conclusão do agendamento.

### ✨ Funcionalidades principais
- [x] **Design Responsivo:** Adaptado para celulares, tablets e computadores.
- [x] **Formulário de Agendamento:** Captura de dados de forma simples e direta.
- [x] **Hierarquia Visual:** Uso estratégico de cores, fontes e espaçamentos para guiar a leitura.
- [x] **Seção Informativa:** Apresentação clara dos serviços oferecidos e benefícios.

---

## 🛠️ Tecnologias Utilizadas

Para manter o projeto leve, rápido e de fácil manutenção, utilizei tecnologias web fundamentais:

- **HTML5:** Estruturação semântica de todo o conteúdo e formulários.
- **CSS3:** Estilização completa, layouts (Flexbox/Grid), tipografia e design responsivo.
- **GitHub Pages:** Hospedagem automatizada e gratuita do deploy.
